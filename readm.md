# Sistema de Gestão de Funcionários

## Sobre o projeto

O Sistema de Gestão de Funcionários é uma aplicação web desenvolvida para facilitar o cadastro, a organização e o gerenciamento de informações de colaboradores de uma empresa.

O projeto permite registrar funcionários, consultar dados, editar cadastros, excluir registros e acompanhar indicadores relacionados à equipe e à folha salarial.

## Objetivo

Desenvolver uma aplicação prática para demonstrar conhecimentos em desenvolvimento web, lógica de programação e armazenamento de dados no navegador, simulando uma ferramenta utilizada em rotinas administrativas e de Recursos Humanos.

## Funcionalidades

- Cadastro de funcionários.
- Edição de informações dos colaboradores.
- Exclusão de funcionários.
- Pesquisa por nome, CPF, cargo ou departamento.
- Cálculo automático da folha salarial.
- Contagem de funcionários cadastrados.
- Identificação dos departamentos existentes.
- Armazenamento de dados com LocalStorage.

## Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e responsividade.
- JavaScript — funcionalidades e regras de negócio.
- LocalStorage — armazenamento dos dados no navegador.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
4. Utilize o formulário para cadastrar funcionários.
